Capturas para la ayuda in-app
=============================

Colocá acá archivos PNG con estos nombres exactos para que aparezcan
dentro de cada artículo de ayuda:

  nuevo-proveedor.png   → modal "Nuevo proveedor"
  viaje-modal.png       → modal de carga de viaje en Flota Pesada
  sucursales-config.png → ⚙ → Sucursales y empresas
  nueva-factura.png     → modal "Nueva factura"
  nueva-oc.png          → modal "Nueva orden de compra"
  vista-dia.png         → pestaña Día

Si el archivo no existe, el artículo se muestra igual (sin imagen).
